## 1. Housing Price Forecasting Model

### Business Problem

A real estate agency needed a model capable of predicting housing prices based on property characteristics.

### Project Highlights

* Data cleaning and preprocessing
* Feature engineering
* Statistical analysis
* Model comparison
* Hyperparameter tuning
* Model deployment via FastAPI

### Models Tested

* Linear Regression
* Lasso Regression
* Random Forest
* Gradient Boosting
* XGBoost
* CatBoost

### Final Results

* MAE: 98,320
* RMSE: 223,736
* R²: 0.756

### Technologies

Python, Pandas, Scikit-learn, XGBoost, CatBoost, Optuna, FastAPI

## 3. A/B Testing Analysis of Landing Page Variants

### Business Problem

Evaluate two landing page versions for a travel agency and determine which version performs better.

### Key Metrics

* Conversion Rate
* Average Order Value (AOV)

### Project Highlights

* Experiment validation
* Metric stabilization analysis
* Confidence intervals
* Statistical hypothesis testing
* Business interpretation of results

### Result

No statistically significant difference in conversion rates was found.

However, Landing Page B demonstrated a significantly higher Average Order Value (AOV) and was recommended for deployment.

### Technologies

Python, Pandas, SciPy, Matplotlib, Seaborn
